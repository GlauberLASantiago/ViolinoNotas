🎻 Notas na Primeira Posição: Violino

Uma aplicação web interativa desenvolvida para auxiliar estudantes de violino iniciantes e intermediários a visualizarem a localização das notas e a digitação correta na primeira posição do instrumento.

✨ Funcionalidades

Seleção de Armadura de Clave: Suporte para tonalidades com sustenidos e bemóis (ex: Sol Maior, Ré Maior, Si Bemol Maior, etc.).

Visualização do Braço: Representação gráfica precisa do espelho do violino com as 4 cordas (Sol, Ré, Lá, Mi).

Digitação Inteligente:

Indica qual dedo utilizar (1, 2, 3, 4) ou corda solta (0).

Ajusta automaticamente a posição dos dedos (ex: 2º dedo alto vs. 2º dedo baixo) baseado na tonalidade.

Lógica específica para evitar o uso desnecessário do 4º dedo quando a corda solta equivalente está disponível (exceto na corda Mi).

Intervalos: Marcação visual de Tons (T) e Semitons (S) acima da corda Mi e abaixo da corda Sol para facilitar o estudo teórico.

Correção Enarmônica: Exibição correta de notas como Mi# em tonalidades com muitos sustenidos.

Design Responsivo: Interface limpa e adaptável a dispositivos móveis e desktops, com tema de cores suave ("Stone") para não cansar a vista.

🚀 Como usar

Não é necessário instalação ou servidor. O projeto consiste em um arquivo único.

Baixe o arquivo index.html.

Abra-o diretamente em seu navegador (Chrome, Firefox, Edge, Safari).

Selecione a quantidade de acidentes no menu superior para ver as notas correspondentes no braço do violino.

🛠️ Tecnologias Utilizadas

HTML5 & SVG: Para estrutura e desenho vetorial do braço do violino.

CSS3 (Tailwind CSS): Estilização moderna e responsiva (via CDN).

JavaScript (Vanilla): Lógica matemática para cálculo de frequências, posições de semitons e renderização dinâmica.
